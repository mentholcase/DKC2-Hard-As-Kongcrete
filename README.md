=== Must be patched to version (U)(V1.0) of the DKC2 rom ===
<br>
- Either download NUPS to patch your rom [ http://www.romhacking.net/utilities/606/ ] or patch it online via an online rom patcher [ https://www.romhacking.net/patch/ ]
- Included is an SRM file with three saves:
	- 1 - all levels unlocked
	- 2 - all levels up to Stronghold Showdown unlocked
	- 3 - duplicate of #2
- If you wish to use those three saves, simply rename the SRM file to match the ROM file, but while keeping the ".srm" extension. For example, if your ROM file is named "DKC2legalbackup.sfc", you would rename the SRM file to "DKC2legalbackup.srm".
- also included is a file named DK Coin Hints.txt, with hints to the whereabouts of DK Coins not found as end-of-level targets.

===IMPORTANT===
<br>
If you wish to start a new save file with Hard As Kongcrete, you must use the BARRALAX cheat code. There are NO DK barrels in this hack, so without BARRALAX, losing either Diddy or Dixie will be a PERMANENT loss, and it will be impossible to advance in the game. The BARRALAX code is already implemented in the aforementioned save files. To enter this code, select a new save file & press DOWN several times until the cheat menu appears. Then press

B, A, RIGHT, RIGHT, A, LEFT, A, X

You should hear Diddy Kong make a sound if inputted correctly. Now select a new game.

==BOSSES==
<br>
For whatever reason the original developers decided, the BARRALAX cheat does not implement when starting a boss level, so before fighting a boss, please go to a previous level to obtain both Kongs, & then press START SELECT.
